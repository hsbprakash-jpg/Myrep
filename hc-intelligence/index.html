Semantic definitions

MeasureDefinition
Current headcountCurrent-month Total Physical plus Total Vacant, using Status_RD. If Status_RD is unavailable, the application falls back to Employee ID populated versus blank.
Vacant positionEmployee ID is blank; counted distinctly by Position ID/Position Number.
Total positionsDistinct Position IDs/Position Numbers.
Vacancy rateVacant positions divided by total positions.
New joiners this monthCurrent-month records where Joiners equals YES and Joiners Month matches the current reporting month.
Future joinersCurrent-month records where Joiners equals YES and Joiners Month is after the current reporting month.
Future leaversCurrent-month records where Leavers equals YES.
LeaverEmployee ID exists in prior month but not current month.
Position changeSame Employee ID exists in both files but Position ID differs.
Employee lookupSearches only the current-month Employee Name field using a partial, case-insensitive match and returns Employee ID, Position Number, OLD_EMP_RD, Functional Manager and FRC Code.
Joiner detailEmployee ID exists in current month but not prior month; returns joining date, position and functional manager.
Leaver detailEmployee ID exists in prior month but not current month; returns exit date, position and functional manager.
Leaver approval exceptionLeaver where COO Status or OPCO Status is not Completed. Blank approval status is treated as pending.
Copy TableCopies the formatted result table for direct pasting into Outlook, Teams or Word.
Copy EmailCopies an email-ready introduction, formatted result table, record count and closing.
